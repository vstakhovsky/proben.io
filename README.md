# Proben.io

Meeting Readiness Assessment for Solo Founders.

## Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Run tests
pnpm test

# Type check
pnpm type-check
```

## Phase 1 MVP

This is a static public demo with:
- Landing page (`/`)
- Sample readiness report (`/sample-report`)
- Readiness check demo (`/app/readiness-check`)
- Portfolio/build-process page (`/portfolio/build-process`)

No database, authentication, or external services required.
