# Source to Visual Skill

## Purpose

Take a source card and produce visualization ideas—diagram recommendations, drafts, and narrative explanations.

## When to Use

When a source card has been created and we need to visualize the pattern:
- Agent looping pattern → flow diagrams
- Context optimization → context pack diagram
- Visual planning → lifecycle diagram
- Validation process → gates diagram

## Behavior

### Input Analysis

1. **Read source card**
   - What's the core pattern?
   - What are the key components?
   - What's the flow or structure?

2. **Identify visualizable elements**
   - Is this a process flow? → Flowchart
   - Is this a hierarchy? → Graph
   - Is this a comparison? → Table
   - Is this a lifecycle? → State diagram

3. **Recommend diagram type**
   - Which diagram type fits best?
   - What's the key message?
   - Who's the audience?

4. **Create diagram draft**
   - What are the key nodes?
   - What are the connections?
   - Where are the decision points?

5. **Write narrative explanation**
   - What does this diagram show?
   - Why does it matter?
   - How does it apply to Proben.io?

## Inputs

- Source card (with pattern analysis)
- Target audience (technical/non-technical)
- Context (docs/portfolio/team)

## Outputs

- Diagram type recommendation
- Diagram structure draft (nodes, edges, labels)
- Narrative explanation
- Acceptance criteria for final diagram

## Example

**Input**: Source card for agent looping

**Output**:
1. Recommend: Fleet loop flowchart
2. Structure: Orchestrator → Specialist Assignment → Synthesis → Human Approval → Implementation → Verification
3. Key nodes: Orchestrator, Research Analyst, Product Manager, Lead Architect, Security Reviewer, QA Release Engineer, Documentation Engineer
4. Decision node: Human approval gate
5. Narrative: "This diagram shows how the orchestrator coordinates specialist agents for complex tasks..."
